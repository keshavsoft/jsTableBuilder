TableBuilder Documentation

TableBuilder is a configuration-driven frontend rendering library. Its purpose is to convert structured configuration and data into maintainable DOM-based UI components.

Documentation

  • Architecture — Overall system architecture and responsibility boundaries.
  • Coding Standards — Naming, input conventions, exports, folder structure, and implementation rules.
  • Rendering Pipeline — How configuration becomes DOM through builders and Web Components.
  • Configuration — Public configuration, internal configuration, defaults, mapping, and validation.
  • Versioning — Versioned implementations and explicit version selection.

Core Principle

Configuration describes what the UI should represent. Builders decide how the DOM is composed. Components own specific UI behavior.
