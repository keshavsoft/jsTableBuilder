Full-Stack Project Generator Documentation

Short guide for project creation, Express API generation, routing, endpoints and frontend table UI.

ProjectAPIActionsFrontendFlow

1. Project Creation

VS Code→Boilerplate→Template→Project
Install Extension

Install ks-express-boilerplate from the VS Code Marketplace.

Right Click

Right-click the project folder and choose an Express BoilerPlate template.

Show Html

Open Show Html to view available templates.

Select Template

Select labManagement; the selected boilerplate is copied into the output project.

The generated project contains the Express starter files such as app.js, routes.js, server.js, configuration and environment files.

3. Start Endpoint Creation

startEndPoint starts API generation from the existing Express application.

  1. Open app.js.
  2. Run the startEndPoint action.
  3. Enter an optional API folder name such as Api.
  4. Select the endpoint style and build it.

The generator creates the API structure and prepares it for router registration.

4. Add Sub-Route

AddSubRoute creates a version-level router and connects it to the parent router.

Api/routes.js→Api/V1/routes.js→Table route

Example: the parent router mounts /V1 and the V1 router handles table-level routes.

5. Add Table Name HTML

AddTableNameHtml opens the schema/table selection UI and prepares the selected table for endpoint generation.

Schema

Tables are selected from Config/Schemas.

Example

Select doctors.json for the Doctors table.

Result

The selected schema becomes the endpoint-generation target.

6. Generate Table API

For a selected table such as doctors.json, the extension creates an end-points.js file and action folders.

Api/V1/doctors/
├── end-points.js
└── showAll/
    └── controller.js

The endpoint file keeps the table name, data path, schema/config path and Express router.

7. GET Actions

GET actions provide read-oriented operations for the selected table.

Action Help
showAll Return all records.
find Find matching records.
FilterQuery Filter records from query information.
lastRecord Return the last record.
firstRecord Return the first record.
distinct Return distinct values.
count Return record count.
min / max Return minimum or maximum values.

8. POST Actions

POST actions provide insert and query operations.

Action Help
insertGenPk Insert data with generated primary key.
find Find matching records.
FilterQuery Filter using query information.
groupBy Group records by a query column.
insertWithMeta Insert data with metadata such as date stamp and UUID.

9. Generated Endpoint Example

router.get('/showAll', (req, res) =>
  funcFromshowAll({ req, res, inTablePath: tablePath })
);

For POST actions, the generator adds JSON body handling and the generated controller call.

16. Backend + Frontend Integration

The backend generator creates the API; the frontend calls the API and passes the returned JSON into jsTableBuilder.

Schema→Generated API→JSON Data→Columns→TableBuilder

17. Complete Workflow

  1. Install the boilerplate extension.
  2. Right-click the project and select a boilerplate template.
  3. Open Show Html and select labManagement or another template.
  4. Generate the starter project.
  5. Open app.js and run startEndPoint.
  6. Add the API root and a version such as V1.
  7. Use AddTableNameHtml to select a schema/table.
  8. Generate end-points.js.
  9. Generate required GET and POST actions.
  10. Connect the generated router to the Express application.
  11. Load jsTableBuilder in the frontend.
  12. Provide API/JSON data and column configuration.
  13. Render the table using TableBuilder.

18. Developer Checklist

Item Done When
Boilerplate Starter project is generated.

V1 Route Version route is connected.

19. One-Line Summary

Boilerplate creates the project → Endpoint tools create routes/APIs → Schema selects the table → GET/POST actions create operations → jsTableBuilder converts data + columns into the frontend table UI.
