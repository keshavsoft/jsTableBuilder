TableBuilder

Setup, Run and View Generated Table Documentation

Developer Documentation

1. Introduction

TableBuilder is a configuration-driven table rendering project. After cloning the project and installing its dependencies, the test application can be started from the test folder.

The generated table can then be opened in a browser using the corresponding local URL. In this example, the generated table is called BillsTable.

Purpose: This document explains how to install the project, start the test server, open the generated table, and verify the final output in the browser.

2. Application Flow

The complete process follows the flow below:

Clone Project
→
Install Dependencies
→
Open test Folder
→
Run Server
→
Open BillsTable
1

Clone the Project

First, clone the TableBuilder project from the repository and open the project folder in VS Code. 

git clone https://github.com/keshavsoft/jsTableBuilder
cd JsTableBuilder
After cloning the project, the project source code and required configuration files will be available in the local workspace.
2

Install Project Dependencies

Open the terminal inside the project root directory and install all required Node.js dependencies. 

npm i

This command installs the packages defined in package.json and creates the node_modules folder.

Expected result: The required project dependencies are installed and the project is ready to run.
3

Go to the Test Folder

After installing the dependencies, move into the test directory. 

cd test

The test folder contains the files and generated table configuration used to verify the TableBuilder functionality.

4

Start the Local Server

From inside the test folder, run the following command: 

npx serve

The npx serve command starts a simple local static file server. It makes the files inside the current directory available through a local browser URL.

Important: Keep this terminal running while accessing the TableBuilder page in the browser.
5

Open the BillsTable Path

Once the server is running, open the generated BillsTable path in your browser.

Example:

http://localhost:<PORT>/test/BillsTable/

The exact port number is displayed by npx serve in the terminal.

Note: Do not assume a fixed port number. Use the port shown in your terminal when npx serve starts.
6

View the Generated Table

After opening the BillsTable URL, the browser loads the generated HTML page.

The page displays the table data in a structured tabular format.

Successful Output: The BillsTable page should display columns such as ParentPk, ItemName, vchtype, type, Qty, Amount, and the corresponding table records.

3. Important Test Structure

After entering the test directory, the generated TableBuilder files can be found inside the corresponding table folder.

4. Commands Summary

Step Command Purpose
1 git clone <repository-url> Clone the project
2 npm i Install dependencies
3 cd test Open the test directory
4 npx serve Start the local server
5 Browser URL Open the BillsTable page

5. Troubleshooting

ERR_CONNECTION_REFUSED

If the browser displays ERR_CONNECTION_REFUSED , the local server may not be running or the browser may be using an incorrect port.

Solution: Go back to the terminal and make sure npx serve is still running. Then use the exact localhost URL and port displayed by the terminal.

Incorrect URL

Make sure the URL points to the correct generated table directory, for example:

http://localhost:<PORT>/test/BillsTable/

6. Final Result

When all the above steps are completed successfully, the browser displays the generated BillsTable page.

The table contains the configured columns and records, confirming that the TableBuilder test output is working correctly.

Result: The TableBuilder project has been successfully installed, the test server is running, and the generated table is accessible through the browser.
