jsTableBuilder - How to Test

This document explains how to clone the jsTableBuilder repository and run the test HTML file locally.

Step 1: Clone the Repository

Open PowerShell or Command Prompt and clone the repository:

git clone https://github.com/KeshavSoft/jsTableBuilder.git

Step 2: Navigate to the Project

cd jsTableBuilder

Step 3: Verify the Repository

Check the project files:

dir

The repository contains folders and files such as test, dist, v1, v2, v3, v4, v5, v6, and test HTML files.

Step 4: Check the Test Files

Check the test folder:

dir test

The test folder contains the test configuration and JavaScript files used by the test environment.

Step 5: Start a Local HTTP Server

Run the server from the project root directory: 

python -m http.server 8000

If Python is not available through the python command, use: 

py -m http.server 8000

The server should start on: 

http://localhost:8000/

Step 6: Open the Test HTML

Open the following URL in a browser: 

http://localhost:8000/test.html

Do not open the HTML file directly using file://. The test uses JavaScript modules and resource loading, so it should be served through HTTP.

Step 7: Verify the Test Output

After opening the test page, verify that:

  • The page loads successfully.
  • The header is displayed.
  • The table is displayed.
  • Table data is rendered.
  • The search input is displayed.
  • Action buttons are displayed.
  • View buttons are displayed.
  • Scroll controls are displayed.

Step 8: Check Browser Console

Open Developer Tools using F12 and select the Console tab.

Check for:

  • JavaScript errors
  • Failed resource requests
  • TableBuilder loading errors
  • Module loading errors

Step 9: Check Resource Loading

The test resource loader first attempts to load local resources. If a local resource is unavailable, it attempts the configured remote fallback resource.

Therefore, a local resource returning 404 should be checked against the configured fallback behavior before making any code changes.

Step 10: Verify the TableBuilder Version

The test configuration references the v6 TableBuilder resource.

The repository contains the v6 implementation under: 

v6/tableBuilder.js

The distribution build is also available under: 

dist/v6/tableBuilder.js
Expected Result:

The test HTML should open through the local HTTP server and the jsTableBuilder table UI should render in the browser.

Important:

If local resource paths return 404 but the configured remote fallback resources load successfully, verify the resource configuration before changing the test code.

Stop the Local Server

Return to the PowerShell window running the server and press: 

Ctrl + C
